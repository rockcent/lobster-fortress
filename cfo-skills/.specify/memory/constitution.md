# Constitution — CFO Skills

## Core Principles

### I. 金融分析数据优先
财务数据（comps/earnings/DCF）必须标注数据来源，禁止凭印象填写数字。

### II. AI 分析结论可溯源
每个分析结论必须附有证据链，结论需标注置信度区间。

### III. 输出不构成投资建议
所有输出为研究参考，不构成投资建议，需有免责声明。

### IV. AI 辅助开发规范
涉及分析逻辑变更、AI 模型切换、输出格式变更，必须走 SDD 流程。

## 技术栈
Skill-based：CFO 工作流技能库（equity-research / financial-analysis）

## 项目约束
- 财务数据必须标注来源（SEC/公司财报/第三方）
- 分析结论附置信度
- 明确区分事实陈述与主观判断
